## Featured Work

### Atlas AI

**Autonomous Multi-Agent Data Engineering Platform**

Atlas AI uses **DataHub as an organizational source of truth**, allowing AI agents to investigate an organization's data ecosystem before generating data engineering artifacts.

```text
Natural Language Request
          ↓
     Plan the Task
          ↓
   Query DataHub
          ↓
 Retrieve Context
          ↓
 Generate Artifacts
          ↓
 Deterministic QA
          ↓
   Write Back to DataHub
```

**Built with**

`Next.js` `FastAPI` `PostgreSQL` `DataHub` `MCP` `LLMs`

---

### FinSight AI

**AI-Powered Personal Finance Platform**

A financial intelligence application that allows users to upload bank statements, interact with their financial data using natural language, and generate personalized savings insights.

**Built with**

`Next.js` `FastAPI` `Groq` `LLaMA 3` `PostgreSQL` `LlamaIndex` `Recharts`

---

### FlowMind

**AI Productivity Operating System**

An AI-powered workspace for notes, tasks, and ideas. An agent organizes information and turns it into actionable daily plans and retrospectives.

**Built with**

`Next.js` `Supabase` `Groq` `Mistral` `LangChain` `TypeScript` `shadcn/ui`
